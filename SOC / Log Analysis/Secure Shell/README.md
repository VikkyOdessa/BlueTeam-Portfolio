# Secure Shell

## Scenario

Investigated SSH server logs after suspicious activity was detected. The objective was to identify the attacker, determine successful account compromises, reconstruct the attack timeline, and analyse authentication events.

## Tools Used

- Linux CLI
- grep
- OpenSSH logs

## Key Findings

- Internal attacker identified: 192.168.1.17
- Valid account discovered: sophia
- Successful logins: 2
- Attack timeline reconstructed
- Windows OpenSSH log location identified

## Skills Covered

- SSH log analysis
- Authentication investigation
- Brute-force detection
- User enumeration analysis
- Incident timeline reconstruction
- Windows OpenSSH investigation
